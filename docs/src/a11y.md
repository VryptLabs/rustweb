# Accessibility (a11y)

- `aria-*` and `role` are first-class in `html!` and forwarded to the DOM/SSR output unchanged.
- ARIA typos are rejected at compile time with a suggestion.
- Recommended pattern: every interactive control has an accessible name
  (`aria-label`/`aria-labelledby` or content text); state uses
  `aria-pressed`/`aria-selected`/`aria-expanded`, never color alone.
- Test with `tests/headless.rs::keyboard_a11y_smoke` plus axe in the CI browser job.
